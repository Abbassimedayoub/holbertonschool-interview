## Introduction

At Holberton School, preparing for technical interviews is an important part of developing strong problem-solving and software engineering skills.

This repository contains solutions to algorithmic and data-structure problems completed throughout the training. The projects cover topics such as trees, graphs, sorting, linked lists, dynamic programming, string manipulation, regular expressions, and other interview-oriented challenges.

The solutions are primarily implemented in **Python and C**, providing practice with both high-level programming and low-level programming concepts.

## Weekly Problem Solving

For each assigned problem, the main objectives are to:

- Analyze the problem requirements and constraints.
- Design an appropriate algorithm and data structure.
- Implement an efficient solution.
- Follow programming and code-quality best practices.
- Test the implementation.
- Document the solution when appropriate.

Each problem is organized in its own directory to make the repository easy to navigate.
